# Archived: 2024 "Croatian aggregator" roadmap

These documents describe a December 2024 effort to turn this fork into a
multi-supplier aggregator (tiered commissions, cargo vehicles, analytics).
That direction was abandoned in favor of the peer-to-peer (Turo-model)
conversion described in [`docs/p2p/PLAN.md`](../../p2p/PLAN.md).

Treat completion claims in these files with caution: an audit (2026-07) found
the described backend did not compile (broken review/analytics modules,
mis-imported middleware, non-existent fields) and most features had no UI.
The salvageable parts (commission ledger, Croatian translations, PDF/invoice
groundwork) were repaired and folded into the P2P plan; the rest was removed.
